# Programación Web Dinámica

Sitio educativo desarrollado para acompañar las clases de **Programación Web Dinámica de 6° año**.

El objetivo del proyecto es centralizar el material utilizado durante las clases, incluyendo explicaciones, ejemplos de código y actividades prácticas, mientras los estudiantes desarrollan sus propios proyectos web.

## Tecnologías

- React
- Vite
- JavaScript
- Bootstrap
- React Router
- HTML
- CSS

## Contenidos

Actualmente el sitio incluye:

- Clase 1 — Introducción a React y creación del proyecto
- Clase 2 — Componentes en React
- Clase 3 — Bootstrap en React
- Clase 4 — React Router: páginas, rutas y navegación

El contenido se irá ampliando progresivamente con nuevas clases y ejemplos.

## Objetivo

El sitio funciona como material de consulta para los estudiantes y como ejemplo práctico de los conceptos desarrollados durante la materia.

A medida que se incorporan nuevos temas, el propio sitio también evoluciona aplicando los conceptos aprendidos.

## Próximos contenidos

Se incorporarán temas como:

- Componentes reutilizables y Props
- Estados con useState
- Eventos
- Formularios
- Validaciones
- Manejo de datos
